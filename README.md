# BCSL404 - ADA Lab Programs

This repository contains the lab programs for **BCSL404 (Analysis and Design of Algorithms Lab)**, part of the Bachelor of Engineering in Computer Science curriculum under VTU.

---

## 📘 Overview
The repository includes implementations of core algorithms and problem-solving techniques covered in the ADA lab syllabus.  
Programs are provided as reference material to aid in understanding and practice.
